# Shiva Mahajothi Jewellers - Website Redesign Mockup

Modern luxury website redesign mockup for **Shiva Mahajothi Jewellers (Tirunelveli Town, Tamil Nadu)**.

## Brand Preservation & Features
- **Brand Identity**: Royal Navy & Gold aesthetics preserving the Tamil name (**சிவ மஹாஜோதி ஜுவெல்லர்ஸ்**) & tagline (**தரமே எங்கள் தாரக மந்திரம்**).
- **Interactive Admin Upload Feature**: Includes a live Admin Jewellery Upload modal (+ Admin Add Jewellery button) to dynamically add new gold items to the live product catalogue mockup.
- **Top Gold Rate Bar**: Live market ticker for 24K, 22K Gold, and Silver.
- **8 Jewellery Categories**: Hollow Rope, Dollars & Pendants, Necklace, Chains, Rings, Bangles, Chokers, Earrings.
- **Thangamazhai Gold Savings Scheme**: Exact bilingual Tamil & English terms & conditions.
- **Custom Design Orders**: Customer reference photo upload request modal.
- **B2B & B2C positioning**: Dedicated wholesale supply & retail showroom cards.
- **Contact Details**: 97, West Car Street, A.V Complex, Tirunelveli Town, Tamil Nadu – 627006.
